1. CONTRATO (oráculo = comentário das linhas 13–20)
-------------------------------------------------
time_override_end <contest> <login>
  - ecoa o `end` (epoch) da 1ª regra de contests/<c>/time-overrides.json cujo regex
    casa com o login; vazio se nenhuma.
  - Formato do arquivo: [{regex, end, reason?}, …] — 1ª que casa vence.
  - try/catch protege de regex inválido (regra pulada).
  - Só vale com o módulo `sedes` ligado (decisão do Ribas, 03/10/2026); o teste do
    módulo vem DEPOIS do teste do arquivo.

Código:
  local f="$CONTESTSDIR/$1/time-overrides.json"
  [[ -s "$f" && -n "${2:-}" ]] || return 0                         # D1
  _tov_on "$1" || return 0                                          # D2/D3
  jq -r --arg l "$2" 'first(.[]? | (.regex // "") as $rr | (.end) as $e
        | select($rr != "" and ($e|type=="number") and (try ($l|test($rr)) catch false))
        | $e) // empty' "$f" 2>/dev/null                            # D4–D7
  _tov_on(){ declare -F mod_on >/dev/null || source "${_LIBDIR:-…}/modules.sh"; mod_on "$1" sedes; }
